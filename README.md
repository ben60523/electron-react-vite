# electron-react-vite

This template is the cross-platform application with Electron framework which is along with React and Vite. (HMR is valid)
This project is inspired by [clh/Electron + Vite + Typescript + React -- 桌面應用開發 ep1. 環境設定](https://hackmd.io/@clh/electron-1)

## Quick Start
```
npm install
npm run transpile:electron
npm run dev
```

## Structure
* dist (Setup files(Application Installer)) - Exist after `npm run dist`
* dist-electron (Built main process files of Electron) - Exist after `npm run transpile:electron`
* dist-react (Built renderer process files of Electron (React)) - Exist after `npm run build`
* node_modules (dependencies are here) - Exist after `npm run install`
* public (icon, other public resources)
* src (code)
  * assets (pics, sound, and others)
  * electron (main process code)
  * ui (renderer process code (React))
* .gitignore
* electron-builder.json (configuration for `electron-builder`)
* eslint-config.js
* index.html
* package.json
* tsconfig.app.json (Typescript settings for React)
* tsconfig.node.json (Typescript settings for Node)
* tsconfig.json (Global Typescript settings)
* tsconfig.tsbuildinfo (Generated by Typescript) - Exist after `npm run transpile:electron`
* vite.config.js (Configurations for Vite)

## Scripts

1. `npm run dev` 
   * Start App with Development mode
2. `npm dist:${os.platform}`
   * Create a distributable setup file for specific platform
     * Supported platform 
       1. windows(x64)
       2. mac(arm64)
       3. linux(x64)

## Apply code changes
* For React, If `npm run dev` or `npm run dev:react` is running. You won't need to do anything for applying code changing because Vite is HMR.
* For Electron main process, 
    1. Quit the current App if it's running
    2. Run `npm run transpile:electron` to build the code of main process 
    3. Run `npm run dev` to restart the App
